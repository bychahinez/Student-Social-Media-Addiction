# Student-Social-Media-Addiction
This project uses Artificial Intelligence to predict social media addiction scores among students. By analyzing behavioral, emotional, and academic patterns



## 🎯 Objectives

- Understand what causes social media addiction
- Explore how sleep, focus, and mental well-being are impacted
- Help schools and parents build smarter prevention strategies

---

## 📁 Dataset

The dataset used in this project is available on Kaggle:

🔗 [Student Social Media Addiction – Kaggle](https://www.kaggle.com/datasets/adilshamim8/social-media-addiction-vs-relationships)

It includes:
- Demographics (Age, Gender, Country, Academic Level)
- Social Media Behavior (Daily Hours, Most Used Platform)
- Mental Health & Emotional Aspects
- Academic and Social Impacts
- Addiction Score (target variable)
