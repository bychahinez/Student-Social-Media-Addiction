# Student-Social-Media-Addiction
This project uses Artificial Intelligence to predict social media addiction scores among students. By analyzing behavioral, emotional, and academic patterns



## 🎯 Objectives

- Understand what causes social media addiction
- Explore how sleep, focus, and mental well-being are impacted
- Help schools and parents build smarter prevention strategies

---
---

## 🧠 Project Workflow

1. **Exploratory Data Analysis (EDA)**  
   Histograms, pie charts, bar plots, and world maps

2. **Data Preprocessing**  
   - Cleaning column names  
   - Label Encoding categorical features  
   - Handling missing and duplicate values

3. **Correlation Analysis**  
   - Identifying key features that affect addiction scores  
   - Feature selection for modeling

4. **Machine Learning Models**  
   - 🟠 *Regression:* Random Forest Regressor to predict addiction score  
   - 🔵 *Classification:* Random Forest Classifier to categorize addiction level (Low, Medium, High)

5. **Class Imbalance Handling**  
   - SMOTE (Synthetic Minority Oversampling Technique)

6. **Model Evaluation**  
   - MSE, R² for regression  
   - Accuracy, precision, recall, F1-score, confusion matrix for classification  
   - Feature importance visualization

---

## 📈 Results

- **Regression Model:**  
  - MSE: ~0.05  
  - R² Score: ~0.98

- **Classification Model:**  
  - Accuracy: 99%  
  - Balanced class prediction using SMOTE

## 📁 Dataset

The dataset used in this project is available on Kaggle:

🔗 [Student Social Media Addiction – Kaggle](https://www.kaggle.com/datasets/adilshamim8/social-media-addiction-vs-relationships)

It includes:
- Demographics (Age, Gender, Country, Academic Level)
- Social Media Behavior (Daily Hours, Most Used Platform)
- Mental Health & Emotional Aspects
- Academic and Social Impacts
- Addiction Score (target variable)
